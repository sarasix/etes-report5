Balanced event credit with temporal tie-breaking

1. Give each event type equal total weight

w(e) = 1 / |Em|,   e ∈ Em,   m ∈ {subtitle, scene}

Em is the set of events of type m. Four subtitle events receive 1/4 each; twenty scene events receive 1/20 each. An absent event type contributes nothing.

2. Score events not yet represented

Δ(t | S) = ∑e ∈ E(t) w(e) · 𝟙[e ∉ Cov(S)]

S is the set of selected candidate times. E(t) contains events represented by candidate t; Cov(S) contains events already represented. The indicator 𝟙 equals 1 for an uncovered event and 0 otherwise; it is not a probability.

3. Measure distance from the nearest selected frame

d(t,S) = mins ∈ S |t − s|,   d(t,∅) = 0

A larger distance means the candidate is farther from its nearest selected frame.

4. Select one frame at a time

t* = arg maxt ∈ C ∖ Slex (Δ(t | S), d(t,S), ρscene(t), −t)
S ← S ∪ {t*},   until |S| = min(16, |C|)

C is the candidate set sampled at approximately one frame per second. Compare event credit first. Only when tied, compare temporal distance, then scene-strength rank ρscene, then prefer the earlier time. Return the selected frames in chronological order.

Implementation scope: each event belongs to one candidate, so selecting it does not lower other candidates' event credit. Temporal distance is a tie-breaker, not a guarantee of visual diversity. No first or last frame is mandatory.
